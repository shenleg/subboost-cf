# Triage 标签映射

工程技能使用五个标准的分诊（triage）角色。本文件将这些角色映射到本仓库 Issue Tracker 实际使用的标签字符串。

| mattpocock/skills 中的角色 | 本仓库追踪器中的标签 | 含义 |
| -------------------------- | -------------------- | ------------------------------------ |
| `needs-triage`             | `needs-triage`       | 需要维护者评估此 Issue |
| `needs-info`               | `needs-info`         | 等待提交者补充更多信息 |
| `ready-for-agent`          | `ready-for-agent`    | 规格已完整明确，可交由后台 Agent 执行 |
| `ready-for-human`          | `ready-for-human`    | 需要人工开发实现 |
| `wontfix`                  | `wontfix`            | 不予处理 |

当某个技能提及分诊角色（例如“添加可供 AFK Agent 执行的分诊标签”）时，请使用上表中对应的标签字符串。

如需改用其他标签命名，直接编辑“本仓库追踪器中的标签”一列即可。
